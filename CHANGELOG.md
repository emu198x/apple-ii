# Changelog

## 0.1.0 — 2026-11-04

Initial published original NTSC revision-0 machine and shared Apple II runtime.
Monitor and Integer BASIC, text/lo-res/hi-res/mixed video, speaker, keyboard,
slot-6 Disk II and WOZ work disks. Shared scripts and MCP provide exact ticks,
native frames, bounded waits, typing, queries, CPU debugging and captures.
Save states, later boards, cassette and native windows remain future work.

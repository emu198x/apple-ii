# Disk II on the original Apple II

Engineering-frontier continuation after the graphics milestone. Design and both new library dependencies approved by Steve on 4 November
2026. Existing graphics PR #1
has passed all required checks; preserve that work while preparing this slice.

## Proposed outcome

Fit a 16-sector Disk II card in slot 6 of the existing original NTSC revision-0
machine. Execute the caller-supplied P5 bootstrap and P6 sequencer PROMs; read a
WOZ 2 bitstream through the actual controller path. Verify a disk bootstrap and
DOS disk reads through typed Monitor/BASIC commands, retaining media identities
and observed output. No ROM traps or direct sector injection into machine RAM.

The proposed alternative is NIB first. It would be smaller but carries less
recorded timing. Prefer WOZ 2 so track length, quarter-track mappings and bit
rate survive mounting. This is an initial 5.25-inch bitstream surface, not a
claim that all WOZ versions, flux chunks or copy protections are qualified.

## Ownership and boundaries

- `Emu198x/apple-disk-ii/`: standalone `emu198x-apple-disk-ii` peripheral,
  following workspace-shape.md's peripheral-repository rule. Controller and
  drives operate on owned bit tracks, independent of file layouts and machine
  types. Caller supplies both 256-byte PROMs; commit neither.
- `Format198x/format198x/crates/format198x-apple-ii-woz/`: dependency-free
  `format198x-apple-ii-woz`, originated by this emulator need and placed under
  the all-Emu198x-layouts graduation rule. Read and write WOZ 2; preserve opaque
  chunks and metadata, validate bounds/maps/counts/CRC, and reject unsupported
  playback surfaces explicitly. Record design in `decisions/apple-ii-woz.md`.
- `Emu198x/apple-ii/`: thin format-to-track adapter and slot-6 wiring. Depend
  on published versions of those libraries; no git revisions or permanent
  local-path dependencies. Existing constructor and display APIs remain valid.
- Mounted source files remain immutable. Archive mounts are write-protected.
  An explicitly writable work mount may change its in-memory tracks. Export
  uses a new caller-chosen path with overwrite prevention. Do not add automatic
  write-back to a loaded path or claim save-state persistence in this slice.

## Completed qualification

The separate peripheral and WOZ libraries are published at 0.1.0. The machine
uses those registry releases. Authored-sector boot, DOS CATALOG, protected SAVE,
work-copy SAVE, export and fresh-machine LOAD/RUN pass. The program prints 42.
Source media stays unchanged. See docs/verification.md and docs/disk-fixtures.json
for reproducible commands, identities and retained evidence.

One write bug was reproduced: absolute-angle quantization merged adjacent
transitions (98 survived out of 100). Interval normalization fixes ordinary
DOS writes; exact angular splices and sub-cell flux remain unqualified. The
head model is instantaneous equilibrium, not acceleration/settling. Reference
agreement covers the PROM update block and the stepper's specified equilibria,
not a whole running MAME comparison. Native UI, other slots and later boards
remain outside this milestone.
